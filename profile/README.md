# Intertrons

Intertrons builds [KeeperDesk](https://intertrons.com/keeperdesk), software that
helps service teams keep customer promises from getting lost between calls,
messages, and handoffs.

KeeperDesk notices commitments and recommends what the team should do next. We’re
currently working directly with design partners on focused paid pilots.
